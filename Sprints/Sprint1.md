# Sprint 1: Front-End App Development — CLI Foundation

## 1. สถานะปัจจุบัน

Sprint 1 เสร็จสมบูรณ์แล้วและผ่านการตรวจสอบด้วยการรันเทสต์จริงของโปรเจกต์ โดยผลการทดสอบรวม ณ ปิด Sprint: **35 passed** (ปัจจุบันทั้งโปรเจกต์มี 93 เคส ดู [Sprint4.md](Sprint4.md))

## 2. Scope ที่ทำเสร็จ

### Phase 1: Planning

- กำหนดขอบเขตระบบ CLI ใน [PLAN.md](../PLAN.md)
- จัดทำโครงสร้าง Presentation Layer ให้แยกจาก Business Logic และ Data Layer
- นิยาม Definition of Done สำหรับ UI/CLI และการตรวจสอบอินพุต

### Phase 2: Execution

- สร้างเมนูหลักและข้อความต้อนรับใน [src/cli.py](../src/cli.py)
- รองรับคำสั่งต่าง ๆ: Play, View History, View Statistics, How to Play, Exit
- จัดการ input validation สำหรับเมนูและคำทาย
- รองรับคำสั่ง `hint` และ `answer` ระหว่างเล่นเกม
- ใช้ `.strip()` และ lowercase normalization สำหรับคำสั่งผู้ใช้

### Phase 3: Review & Testing

- ตรวจสอบความถูกต้องของอินพุตด้วย edge case เช่น ค่าว่าง, ตัวอักษรผิด, ตัวเลข, คำสั่งใหญ่เล็กต่างกัน
- ตรวจสอบว่าโปรแกรมไม่ทำงานหลุดจากการกรอกข้อมูลที่ผิด
- ทำการทดสอบจริงผ่าน `python -m pytest -q`
